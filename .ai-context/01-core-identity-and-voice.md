## 3. Tom de Voz
- **Consultivo e Especialista:** Falamos com clareza sobre nutrição e suplementação sem jargões desnecessários e sem fazer promessas milagrosas.
- **Ágil e Comercial:** Cada interação visa aproximar o cliente da unidade física mais conveniente para retirada ou entrega expressa.
- **Empático e Transparente:** Avisamos quando uma mensagem é gerada com assistência de IA e garantimos transbordo imediato para o atendente humano quando solicitado.

## 4. Vocabulário Obrigatório vs Proibido
- NUNCA usar "remédio" ou "medicamento" → Sempre usar "suplemento alimentar".
- NUNCA usar promessas de "cura" → Usar "auxilia", "contribui" ou "dá suporte nutricional".
- NUNCA usar "deletar" → Usar "excluir".
- NUNCA usar "logar" → Usar "entrar".
- NUNCA omitir a unidade física quando o cliente perguntar de estoque.
